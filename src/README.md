# Introdução

A ideia deste projeto é passar pelos conceitos de desenvolvimento de software usando JavaScript e React. O objetivo é desenvolver um aplicativo de controle financeiro simples, onde os usuários podem adicionar suas receitas e despesas, e visualizar um resumo financeiro.

## Funcionalidades

- Adicionar receitas e despesas
- Visualizar um resumo financeiro
- Editar e excluir entradas
- Filtrar por categoria e data

## Tecnologias Utilizadas

- React para a construção da interface do usuário
- JavaScript para a lógica de negócios
- CSS para o estilo da aplicação
- LocalStorage para persistência de dados que posteriormente pode ser substituído pelo MySQL
