# Visão Geral

Para fixar os conceitos apresentados, vamos ver uma série de projetos práticos. O primeiro deles é o clássico "Hello World", onde criaremos uma aplicação simples que exibe essa mensagem.

A ideia é que, ao final de cada projeto, você tenha uma aplicação funcional e compreenda os conceitos envolvidos na sua construção. Além disso, cada projeto servirá como base para o próximo, permitindo que você construa conhecimento de forma incremental.
